INWARD PERSPECTIVE EXPLORER - PRIMER
======================================

What this is
-------------
An animated widget for the "Inward perspective" axis of the Psychological
Characterization scale. Lives on its own page,
content/docs/psychoactive/inward/_index.md (served at
/docs/psychoactive/inward/, bookHidden so it doesn't clutter the left nav -
linked instead from the "Psychological Characterization" section of
content/docs/psychoactive/_index.md), embedded via
<div id="inward-perspective-explorer-widget">. That id must stay distinct
from the page's "Inward Perspective Explorer" heading, whose auto-generated
anchor is id="inward-perspective-explorer" - a past collision there caused
document.getElementById to grab the heading instead of the mount div,
sticking the widget above the page's own instructions text. Three fixed
vertices - Self, blended, unblended - form a triangle. A dashed, wobbling
"attention perimeter" wraps around a Self circle (radius grows with ambient
"Self energy", set via a rotary knob at the Self vertex) and one circle per
drifting emoji "part" that fades in/out on its own, plus dose sliders for
named substances. At high enough drug-driven "blending pressure" the
perimeter can instead collapse onto a single part (or small linked group),
excluding Self entirely - "Private reverie".

Entry point: src/inward-perspective-explorer.ts's `InwardPerspectiveExplorer`
class, instantiated directly against the container div at module load.

No test suite. Verify changes by loading /docs/psychoactive/inward/ in a
browser (?debug=1 adds a geometry/field overlay and a shrinkWrap override
slider) and exercising the Self knob, dose picker/administer flow, drug
wheel, Remove part button, and part dragging.

File map
--------
- src/inward/geometry.ts - triangle/vertex constants, `clampPartPosition`,
  `sigmoid(x, midpoint, steepness)` (used throughout for smooth 0..1
  thresholds instead of hard cutoffs), `lerp`.

- src/inward/drugData.ts - the substance model (no rendering/UI).
  `DrugEffect`: dosing shape (`doseSteps` vs free 0-100 slider via
  `doseUnitRange`/`doseUnitLogRange`), Self-energy contribution
  (`selfEnergyBoostSteps`/`selfEnergyBoostMax`), direct per-part pushes on
  a shared 0..1 "blending force" scale (`unblendPushMax` - THH,
  `blendPushMax` - N,N-DMT, mirror images, may exceed 1), `rendersAsPart`
  (cannabis spawns as its own drifting part instead of acting on the
  region), `blendUrgencyDivisor` (5-MAPB, quiets all parts) and
  `cannabisBlendUrgencyDivisor` (THH, quiets cannabis specifically).
  `DRUGS`/`DRUG_BY_KEY` is the substance list. `INTERACTIONS` is explicit
  named pairs only, every entry a hard block (no separate "caution" tier) -
  a pair absent from the table is allowed; opposing forces (e.g. THH vs
  N,N-DMT) net-cancel in the physics instead of needing an interaction
  entry.

- src/inward/part.ts - `Part` type: a drifting emoji's live state (x/y/vx/
  vy, opacity, fadingOut, SVG element, `blendUrgency`, `extraLinkTo` - an
  optional undirected link to one other part rolled at spawn time,
  `hyperFocused` - true while part of Private reverie's target/group).
  `PARTS_PALETTE` is the pool random parts are drawn from.

- src/inward/attnPerimeter.ts - pure attention-perimeter geometry
  (Circle[]/Capsule[]/Part[] in, no drug knowledge). The perimeter is a
  metaball isoline (not a parametric shape - no single radius/centroid),
  extracted via marching squares:
  - `buildCircles` - one circle for Self (radius from `selfCircleRadius`)
    plus one per part; in Private reverie mode (`focusedParts` non-empty)
    Self is excluded and only those parts' circles are returned.
  - `buildConnectorCapsules`/`buildFocusCapsules` - explicit capsule
    corridors guarantee connectivity (star topology from Self, or along
    `extraLinkTo` edges in reverie mode) regardless of the metaball field's
    falloff.
  - `fieldAt`/`thresholdFor`/`marchingSquaresContour` - the scalar field,
    isoline threshold (loose=soft padded oval, tight capped at 0.78), and
    grid extraction. Grid cell size and bounding-box margin are both
    derived from the threshold/circle/capsule sizes actually present, not
    fixed constants - a thin corridor or a loose isoline can otherwise slip
    through undetected.
  - `erodeContour` - pulls contour points inward at tight shrinkWrap so
    multi-circle clusters don't puff out across their convex hull.
  - `buildAttnPerimeterPath` - ties it together: sample field, extract
    isoline, resample, erode, apply sine wobble, render as a dashed path.
  - `computeTargetShrinkWrap(selfEnergy, blendPressure, thhShrinkWrapEffect?)`
    - baseline loosens as Self energy drops; N,N-DMT's blendPressure and
    THH's dose-gated effect both tighten it further.
  - `EMOJI_VERTICAL_CENTER_OFFSET` - part emoji are SVG <text> with y as
    baseline; every circle/capsule endpoint built from a part's (x, y)
    must subtract this or the perimeter reads as offset below the emoji.
  - `BLEND_FORCE_SCALE` - the only place the 0..1 blending-force scale
    converts to actual velocity units; psychological measurements
    (focus-lock sigmoid, force-popup magnitudes) read the pre-scale values.

- src/inward/selfEnergyKnob.ts - `SelfEnergyKnob`: rotary control at the
  Self vertex. Ambient Self energy = drug-set baseline + knob's
  `userFraction` (a fraction of the range *above* the current baseline, not
  an absolute value - `setBaseline()` reinterprets it when baseline
  changes). Polled via `.energy` every frame, no change callback.

- src/inward/doseController.ts - `DoseController`: dosing state + picker
  UI. Dosing is staged (slider moves `pendingDose`; nothing takes effect
  until Administer). `administeredKeys` tracks activity separately from
  dose value (cannabis's 0% is a real nonzero mg floor). The slider and
  Administer button are never disabled - clicking Administer on a
  contraindicated combo (`findContraindication`, checking both the
  `INTERACTIONS` table and 5-MAPB's blanket exclusivity rule) fires
  `onContraindicated` instead of dosing; the parent (top-level class)
  shows a playful modal suggesting removing the other drug first, rather
  than blocking the control or printing an inline warning. 5-MAPB is
  exclusive with everything else in both directions except cannabis and
  psilocybin (`MAPB_COMPATIBLE_KEYS`) - candyflipping-style stacking, no
  interaction entry needed since it's simply allowed. `onDoseChange`
  callback lets the parent react
  (cannabis part sync, Self-energy baseline recompute).

- src/inward/readoutText.ts - word banks for the "Subjective read-out"
  text, keyed off circle count/shrinkWrap/selfEnergy/blendUrgency rather
  than a geometric radius (there isn't one).

- src/inward/drugWheel.ts - `DrugWheel`: pie-menu substance picker UI.

- src/inward/forceOverlay.ts - `ForceOverlay`: per-part hover/click
  force-breakdown popup, conflict ring, and conflict pain-emoji bursts.
  `wirePart`/`removePart` hook a part in/out; `update(part)` is called once
  per part per tick. `FORCE_COLORS` is the legend color table, keyed by
  `PartForce.name`. `maybeSpawnConflictEmoji` throttles a small drifting
  pain-emoji burst (dagger/impact/chains/blood-drop - deliberately
  non-face, since part emoji are already pained faces) per conflicted part.

- src/inward/part.ts also exports `computeConflict(forces)` -
  `min(selfUnblend, blendUrgency)`, the shared pure function behind both
  the conflict ring (ForceOverlay) and the wander-kick-rate check in the
  top-level tick loop - and `pickUnusedPalette(palette, taken)`, used by
  both spontaneous spawn and the manual-add picker so neither repeats an
  emoji already on screen if an unused one is available.

- src/inward/manualPartPanel.ts - `ManualPartPanel`: the Add/Remove-part
  HTML panel below the SVG, plus the spontaneous-spawn on/off toggle. Owns
  its own emoji-picker/urgency-slider/transient-message state; part
  lifecycle stays with the host via its callbacks interface.

- src/inward/contraindicatedModal.ts - `ContraindicatedModal`: the "these
  two drugs don't mix" modal, fed by `DoseController`'s `onContraindicated`
  callback. Picks a random playful template naming both drugs and
  suggesting the other be removed first.

- src/inward/debugOverlay.ts - `DebugOverlay`: everything behind `?debug=1`
  - circle/capsule outlines, the sampled metaball field grid, the text
  readout, and the shrinkWrap override slider (exposed via
  `targetShrinkWrapOverride`, which the host substitutes for
  `computeTargetShrinkWrap()`'s result when non-null). `update()` takes a
  plain state snapshot each tick rather than reading the host's fields
  directly.

- src/inward-perspective-explorer.ts - the top-level class. Owns:
  - SVG scaffold; wires up DoseController/DrugWheel/SelfEnergyKnob/
    ManualPartPanel/ContraindicatedModal/ForceOverlay/DebugOverlay
    (the last only when `?debug=1`). CSS lives in static/css/inward.css,
    linked from the page markdown rather than injected at runtime.
  - `spawnPartAt`/`createPart` - shared part-creation helper (SVG element,
    drag wiring, ForceOverlay wiring) used by every part-creation path
    (spontaneous, manual, cannabis) so wiring can't drift out of sync
    between them.
  - Spontaneous part spawn/reap scheduling, gated by a sigmoid on Self
    energy so very-high Self energy suppresses spawning and forces reaping.
  - `rollExtraLink()` - 50% odds a new part links to an existing one.
  - "Private reverie" (`updateFocusLock`): net pressure
    `max(0, blendPressure() - unblendPressure())` through a hysteretic
    sigmoid (higher threshold to engage than to release, avoids flicker).
    On entry, the highest-urgency part becomes the target; `linkedGroup`
    transitively follows `extraLinkTo` (undirected); cannabis always joins
    the group if present but is never itself `hyperFocused`. On exit,
    `hyperFocused` clears and the group empties.
  - `doseGate(drug)` - converts a drug's 0..1 dose fraction to mg (via
    `doseUnitLogRange`) then through a sigmoid (midpoint 5mg) - shared by
    THH's cannabis-quieting and shrinkWrap-tightening effects, so both ramp
    in with dose instead of flipping on at any nonzero dose.
  - `effectiveBlendUrgency(part)` - the one place drug quieting
    (`blendUrgencyDivisor`, `cannabisBlendUrgencyDivisor`) is applied;
    every reader (physics, focus-lock target selection, readout text)
    should call this rather than reading `part.blendUrgency` directly.
  - The tick loop: per-part physics (wander impulses, push from blended
    scaled by Self energy, THH/N,N-DMT direct pushes, mutual repulsion),
    then rebuilds the perimeter via attnPerimeter.ts. Records a
    `PartForce[]` per part (for ForceOverlay) with `displayMag` on the
    pre-BLEND_FORCE_SCALE 0..1 scale.
  - Part removal cleanup: nulls dangling `extraLinkTo` references, drops
    the reverie group if its target is removed, tells `forceOverlay` to
    drop the part's ring/popup state.

Design invariants (don't break these)
--------------------------------------
- The blending-force scale is 0..1 everywhere except right before it hits
  velocity (`BLEND_FORCE_SCALE`) - tune relative strengths by changing the
  0..1 inputs, not scattered velocity constants.
- The perimeter has no cached centroid/radius - it's a metaball isoline.
  Don't reintroduce one; readout/debug code takes `Circle[]`/shrinkWrap or
  a derived scalar (circle count) instead.
- Connectivity is guaranteed structurally via `Capsule` corridors, not by
  tuning field falloff/background bias - don't "fix" a disconnected
  perimeter by raising `BACKGROUND_FIELD`.
- Self energy is always derived (`SelfEnergyKnob.energy`), never cached.
- `EMOJI_VERTICAL_CENTER_OFFSET` is the single source of truth for the
  emoji baseline/visual-center gap - any new Circle/Capsule endpoint built
  from a part's raw (x, y) needs it subtracted.
